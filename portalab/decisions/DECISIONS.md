# Locked Product Decisions

- Exactly one Admin account.
- No temporary delegation.
- Coins are strictly internal/virtual.
- No real-money coin purchases in current definition.
- All active accounts can vote.
- No minimum voting level.
- Marketplace plugins activate immediately after purchase unless explicit configuration is required.
- Remaining coins are destroyed on final account deletion.
- Admin visibility overrides preserve user preference and restore it afterward.
- Search and AI run in parallel.
- Themes can completely change presentation while preserving functional state.
- Historized does not mean public.
