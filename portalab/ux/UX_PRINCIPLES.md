# UX Principles

1. One environment, not a collection of links.
2. Users should not need to understand technical architecture.
3. Every page answers: Where am I? What can I do? What next?
4. No dead-end empty states.
5. Errors should be actionable.
6. Slow components never block unrelated content.
7. Search is always easy to reach.
8. AI never blocks classic search.
9. Personalization is bounded by security/privacy/business rules.
10. Themes may radically change presentation without changing functional meaning.
11. Accessibility is transversal.
12. Mobile remains functionally complete.
13. Important objects are interconnected.
14. Evolution must not break existing workflows.
