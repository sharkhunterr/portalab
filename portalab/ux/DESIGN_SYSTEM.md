# Design System

Common components:
Card, Panel, Button, Badge, Status, Progress, Table, List, Timeline, Calendar, Chart, Form, Modal, Drawer, Tabs, Avatar, Media Card, Service Card, User Card, Achievement Card, Project Card, Notification.

Standard functional states:
Loading, Available, Partial, Error, Unavailable, Maintenance, Stale, Unauthorized, No data, Syncing.

Components communicate standardized meaning; themes control appearance.
