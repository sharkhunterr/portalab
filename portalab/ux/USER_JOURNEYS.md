# User Journeys

## First connection
Welcome → authentication → profile → services → interests → notifications → privacy → automatic starter dashboard → discovery.

## Daily return
Home → since-last-login → service/activity status → media/progression → direct navigation → action → new event.

## Search
Query → immediate classic results + parallel AI → inspect result → ask AI about results.

## Service problem
Service status → incident/maintenance → Wiki → AI diagnosis → solution → ticket if necessary.

## Media
Consume → service event → portal history → statistics → gamification → achievement/quest → optional community activity.

## Marketplace
Discover → product detail → conditions → purchase with coins → transaction → unlock → immediate plugin activation where applicable.

## Community project
Discover → proposal → vote → optional coin funding → progress → beta/release.

## Support
Ticket type → optional AI diagnosis → prefilled context → user review → submit → status → resolution.

## Privacy
Profile/Data Center → inspect data → visibility/preferences → export/delete.
