# Agent Roles

Product Analyst: interpret product behavior.
UX Agent: design screens and flows.
Architecture Agent: technical structure without changing product rules.
Backend Agent: domain logic, events, permissions, APIs.
Frontend Agent: responsive UI/design system.
Integration Agent: connectors/capabilities.
AI Agent: AI orchestration under user permissions.
QA Agent: business rules, permissions, events, degraded mode, plugin isolation and data integrity.

All agents treat the Product Blueprint and Business Rules as authoritative.
