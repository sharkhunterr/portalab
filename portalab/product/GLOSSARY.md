# Glossary

Portal = complete application/experience layer.
Core = permanent foundations.
Module = major portal area.
Plugin = optional portal functionality.
Connector = external integration.
Service = concrete connected instance.
Capability = functional ability exposed by a connector/service.
Event = something that happened.
History = persisted portal history.
Automation = WHEN/IF/THEN reaction.
Incident = broad/systemic problem.
Ticket = individual user issue.
Notification = portal communication.
News = editorial content.
Marketplace = optional products/unlocks.
Coins = internal virtual currency.
XP = progression.
Contribution = community value.
Achievement = milestone.
Quest = challenge/objective.
Community Project = proposed evolution with votes/funding.
Theme = presentation layer.
