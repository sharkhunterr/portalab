# Age rating marks

`pegi-3.svg` … `pegi-18.svg`: the official PEGI age labels, from Wikimedia Commons
(File:PEGI_3.svg, PEGI_7.svg, PEGI_12.svg, PEGI_16.svg, PEGI_18.svg), released in the **public domain** there
(simple geometry and text). PEGI is a trademark of the Interactive Software Federation of Europe: the marks
are shown only to tell a game's PEGI rating, as its box does. Only the editor's header was removed
and a `<title>` added (« PEGI 7 »).
