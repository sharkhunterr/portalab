# Quickstart — Dashboard
1. Complete onboarding as a new user → starter dashboard exists (policy defaults + mandatory widgets, permission-filtered); re-running onboarding does not duplicate it.
2. Add, hide, reorder (keyboard), resize and configure a widget → persisted across devices; remove one → config gone; hide another → re-add restores config.
3. Admin marks a widget `mandatory` → appears for all and cannot be hidden/removed; relax to `free` → the user's previous state returns.
4. Stop one backing service → only that widget shows `unavailable`; the rest of the dashboard loads normally.
5. Generate news/media/service changes, log in again → "Since Last Login" lists only items the user may see; dismiss advances the boundary; empty case offers a next action.
6. Resize to 360 px → single column in the same order, all functions available.
