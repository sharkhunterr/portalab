# common-passwords.txt.gz

The passwords of 8 characters or more (lower-cased) among the 100,000 most used ones found in data breaches,
as published by the UK's NCSC from Have I Been Pwned: SecLists
`Passwords/Common-Credentials/100k-most-used-passwords-NCSC.txt` (MIT licence, © Daniel Miessler). A member
choosing one of them is refused (issue 406, ASVS 6.2.4). Shorter ones are refused by the length rule anyway.
