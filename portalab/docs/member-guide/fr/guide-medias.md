Trouver un titre dans la médiathèque, lire sa fiche, et le regarder, le lire ou l'écouter sans quitter le portail.

## La page Médias

Ouvrez la rubrique **Médias** du menu : ses onglets sont « Bibliothèque », « Demander un titre », « Mes demandes » et « Mes goûts ». La « Bibliothèque », page d'accueil des médias, vous propose :

- **« Parcourir le catalogue »** pour chercher dans toute la médiathèque ;
- **« Demander un média »** pour demander un titre qui manque (voir [Demander un titre](portalab://wiki/guide-demandes)) ;
- ce qui est **« En cours de lecture »** pour vous en ce moment ;
- des rangées qui défilent sur le côté : **« Reprendre »**, **« Derniers ajouts »**, **« Sorties récentes »**, **« Bientôt retirés »**, **« Lus récemment »**, **« Tendances »**, **« Recommandé pour vous »** ;
- **« Parcourir par type »** : films, séries, livres, livres audio, musique, jeux…

![La page Médias : « Parcourir le catalogue », « Demander un média » et une rangée de titres](shot:medias-accueil)

Une rangée qui n'a rien à montrer n'est pas affichée. Si votre portail a une radio, elle apparaît aussi ici : **« Écouter »** pour l'écouter en direct, et **« Demander au DJ »** pour proposer un morceau.

## Trouver un titre dans le catalogue

Ouvrez [le catalogue](/media/browse), puis :

![Le catalogue : la recherche (1), le type (2), les filtres (3) et le tri (4)](shot:medias-catalogue)

1. Tapez dans **« Rechercher un titre »** : un titre, un auteur, un acteur…
2. Choisissez un **« Type »** : « Tout », « Films », « Séries », « Livres », « Livres audio », « Musique » ou « Jeux ».
3. Affinez avec **« Filtres »** : « Disponibilité », « Déjà consulté » (« Terminé », « En cours », « Pas encore »), « Genre », « Année » (de… à…), et selon le type « Auteur », « Réalisateur », « Narrateur », « Série », « Éditeur »…
4. Classez avec **« Trier par »** : « Ajouts récents », « Titre (A à Z) » ou « Plus récents ».

Les filtres actifs s'affichent au-dessus des résultats. Retirez-en un d'un clic, ou cliquez sur **« Tout effacer »**. Le bouton **« Afficher plus »** charge la suite.

## La fiche d'un titre

Cliquez sur une affiche pour ouvrir la fiche du titre. En haut, vous trouvez l'affiche, l'année, le type, la durée et la note. Juste à côté, des badges :

- **« Disponible »** quand le titre est dans la médiathèque. Sinon, l'étape où en est sa demande (par exemple « En attente de validation » ou « Téléchargement 40 % »), ou **« Indisponible »** ;
- **« En cours · 35 % »** si vous l'avez commencé (ou l'épisode en cours pour une série) ;
- **« Déjà vu »**, **« Déjà lu »**, **« Déjà écouté »** ou **« Déjà joué »** si vous l'avez terminé.

> [!TIP]
> Inutile de regarder tout le générique : quand le serveur multimédia sait où il commence, un film ou un épisode arrêté dans les deux dernières minutes avant le générique de fin compte comme terminé, pour vos statistiques comme pour vos récompenses. Une saison est terminée quand tous ses épisodes sont vus, à la date du dernier.

![Le haut de la fiche d'un film : ses badges, et les boutons pour le regarder](shot:medias-fiche)

Sous le titre, une barre de petites actions :

- les trois icônes de goût : **« J'aime »**, **« Pas pour moi »**, **« Plus tard »** (leur nom s'affiche au survol) ;
- **« Donner mon avis »**, quand vous avez regardé, lu, écouté ou joué le titre : une fenêtre demande une note de 1 à 5 étoiles (chacune dit ce qu'elle veut dire, de « Pas aimé » à « Coup de cœur ! ») et **« Un mot sur ce titre »** si vous voulez, puis **« Publier mon avis »**. Le bouton affiche ensuite votre note (« Mon avis : 4/5 ») et rouvre la fenêtre pour le modifier ou le retirer. L'avis sur un épisode va à sa série ;
- **« Suivre »** pour une série ;
- le drapeau **« Signaler un problème »** : sous-titres manquants, mauvaise langue, fichier coupé, image ? Choisissez ce qui ne va pas (« Sous-titres », « Son », « Image », « Langue », « Fichier illisible ou coupé », « Autre chose »), précisez si besoin, puis **« Envoyer le signalement »**. C'est un ticket du support rattaché au titre, que vous suivez dans [Mes tickets](/support) ; l'équipe voit le titre dans le ticket.

Plus bas, **« Avis des membres »** donne la note moyenne et le nombre d'avis, puis les avis : le vôtre d'abord, les autres signés de leur nom, ou **« Anonyme »** pour un membre qui reste discret dans la communauté. La section n'apparaît qu'une fois un premier avis donné.

Plus bas, selon le titre :

- **« Détails enrichis »** : distribution, équipe, genres, saga, budget et box-office, studios… Cliquez sur une personne pour ouvrir sa page : sa biographie et sa filmographie, avec ce qui est disponible et ce que vous pouvez demander ;
- **« À propos »**, **« Sources »** (où le titre se trouve), **« Demandes »** et **« Liens externes »** ;
- pour un jeu, **« Durée de jeu »** : le temps qu'il faut selon la façon de jouer (« Histoire principale », « Principal + extras », « Complétionniste », « Tous les styles »), avec le nombre de joueurs qui l'ont indiqué (d'après HowLongToBeat, quand RomM le connaît) ;
- **« Mon historique »** : vos lectures de ce titre, la date et jusqu'où vous êtes allé. Quand assez de membres l'ont vu, le nombre de lectures et de membres s'affiche aussi, sans aucun nom.

Si le titre n'est pas encore là, un bouton **« Demander »** le remplace. Si un titre risque d'être supprimé, un encadré **« Bientôt supprimé »** vous prévient (voir [Titres bientôt supprimés](portalab://wiki/guide-bientot-supprime)).

## Regarder un film ou une série

Sur la fiche d'un titre disponible :

- **« Regarder »** ouvre le lecteur du portail en plein écran. Pour une série, le bouton indique l'épisode, par exemple « Regarder S01E03 ».
- **« Reprendre »** repart de là où vous vous étiez arrêté. À côté, deux petits boutons : **« Recommencer »** (depuis le début) et **« Remettre à zéro »** (efface votre point de reprise).
- **« Regarder sur … »**, suivi du nom de votre serveur multimédia (par exemple « Regarder sur Plex »), ouvre le titre dans son application, dans un nouvel onglet.

Dans le lecteur, le bouton **« Réglages de lecture »** permet de choisir :

- la **« Qualité »** : « Originale » lit le fichier tel quel si votre navigateur sait le lire, une qualité plus basse est convertie par le serveur ;
- la **« Version »**, la piste **« Audio »**, les **« Sous-titres »** et leur **« Taille des sous-titres »** ;
- l'**« Amplification audio »** et la **« Vitesse »** ;
- les **« Chapitres »**.

Vous pouvez aussi **« Passer l'intro »** et **« Passer le générique »**. À la fin d'un épisode, **« À suivre »** lance le suivant, sauf si vous choisissez **« Voir le générique »**. Selon votre appareil, le lecteur propose **« Image dans l'image »**, **« Diffuser sur un appareil »** ou **« AirPlay »**.

> [!TIP]
> Raccourcis clavier du lecteur : **Espace** ou **K** pour lecture et pause, **←** et **→** pour reculer ou avancer de 10 secondes, **↑** et **↓** pour le volume, **M** pour couper le son, **F** pour le plein écran, **C** pour les sous-titres, **Échap** pour quitter.

> [!NOTE]
> Selon votre portail, il peut falloir lier votre compte du serveur multimédia pour regarder ici. Le lecteur vous le dit (« Liez votre compte du serveur multimédia pour regarder ici ») et vous mène à vos comptes médias.

## Lire un livre

Sur la fiche d'un livre, **« Lire »** ouvre la liseuse en plein écran. Si vous l'avez commencé, le bouton devient **« Reprendre la lecture (42 %) »**. La liseuse ouvre les formats EPUB, PDF et BD.

Vous y trouvez :

- le **« Sommaire »**, les **« Signets »** (« Marquer cette page ») et **« Rechercher dans le livre »** ;
- les **« Réglages de lecture »** : « Police » (dont « Lecture facilitée »), taille du texte, « Interligne », « Marges », « Couleurs » (« Clair », « Sépia », « Sombre » ou « Selon le thème »), « Défilement continu », « Deux pages côte à côte », et « Lecture de droite à gauche (manga) » pour les BD ;
- **« Retour à la fiche »** pour revenir au titre.

Le bouton **« Lire sur… »** ouvre aussi le livre dans le service de la bibliothèque.

## Écouter un livre audio

Sur la fiche d'un livre audio, **« Écouter »** (ou **« Reprendre »**) lance la lecture dans une barre en bas de l'écran. Elle continue pendant que vous naviguez dans le portail.

**« Agrandir le lecteur »** affiche la couverture et plus de commandes :

- reculer ou avancer de 30 secondes, **« Chapitres »**, chapitre précédent ou suivant ;
- la **« Vitesse »** ;
- un **« Minuteur »** : 10 à 60 minutes, ou **« Fin du chapitre »** ;
- des **« Signets »** (« Ajouter un signet »).

> [!NOTE]
> Votre position est toujours gardée dans le portail. Si le service de la bibliothèque ne la connaît pas, liez votre compte pour la synchroniser.

## Mes goûts

[Mes goûts](/media/taste), dans la rubrique Médias : « Ce que vous regardez, écoutez, lisez et jouez, et ce que vous en dites, fait vos recommandations. »

- **« Dites ce qui vous plaît »** : des titres à juger, l'un après l'autre. Glissez à droite pour « J'aime », à gauche pour « Pas pour moi », ou « Passer ».
- **« Pour vous »** : vos recommandations, par « Type de titre ».
- **« Pour changer »** : « Bien notés, loin de vos habitudes — et peut-être pour vous. »
- **« Ce qui vous plaît »** : les genres, les personnes, les sagas et les thèmes qui reviennent dans vos goûts.
- **« Mes listes »** : « J'aime », « Pas pour moi » et « À voir plus tard ».
- **« Mes données »** : « Utiliser mon historique » (décoché, seuls vos avis comptent) et « Oublier mes avis ».

## Lier vos comptes médias

Ouvrez [Comptes médias](/settings/media-accounts) (dans [Mes paramètres](/settings), « Comptes liés »). Lier vos comptes permet au portail de savoir que votre activité sur ces services est la vôtre : historique, reprise, statistiques, recommandations et, selon votre portail, le lecteur.

1. Dans **« Lier un compte »**, choisissez le service.
2. Indiquez le nom ou le numéro de votre compte sur ce service, puis cliquez sur **« Lier le compte »**.
3. Le compte apparaît **« En attente de vérification »**. Si le service vous a donné un **« Code de vérification »**, saisissez-le puis cliquez sur **« Vérifier »**. Sinon, un administrateur confirme le lien.

Rien ne vous est attribué tant que le lien n'est pas **« Vérifié »**. Vos comptes ont peut-être déjà été liés par l'administrateur : ils apparaissent alors dans **« Comptes liés »**. Pour retirer un compte, cliquez sur **« Supprimer »**.
